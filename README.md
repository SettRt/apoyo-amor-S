# Siempre contigo

Pagina web estatica de apoyo emocional y romantico.

## Como personalizar

1. Agrega tus fotos en `assets/fotos/` con estos nombres:
   - `foto-1.jpg`
   - `foto-2.jpg`
   - `foto-3.jpg`
2. Agrega tu audio en `assets/audio/` con el nombre:
   - `mi-audio.mp3`
3. Abre `index.html` en el navegador para revisar la pagina.

## Para subir a GitHub

Sube toda esta carpeta al repositorio. No necesita servidor local.
